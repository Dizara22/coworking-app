# Коворкинг — мини-приложение Telegram

Расписание кабинетов и рабочих мест (10:00–22:00, шаг 15 минут), база арендаторов, финансы: выручка, расходы, прибыль.

- Весь код — один файл `index.html`, без сервера и сборки.
- Данные хранятся в Telegram CloudStorage — у каждого пользователя бота своё хранилище (лимит 1024 ключа по 4096 символов).
- Если открыть страницу не из Telegram, включается демо-режим с примерами, ничего не сохраняется.
- Хостинг: GitHub Pages. Любой push в ветку `main` обновляет приложение через 1–2 минуты.

## Структура хранилища
- `cfg` — места, цены, минимальная бронь, статьи расходов
- `ten` — арендаторы
- `mГГГГММ` — брони месяца, `eГГГГММ` — разовые расходы месяца, `rex` — ежемесячные расходы

Каждая запись — «блоб»: ключ-заголовок `версия,частей` и части `имя_версия_i` по ≤3900 символов.
Новая версия пишется целиком, затем переключается заголовок — недописанное сохранение не портит данные.

## Резервная копия
«Места» → «Скопировать резервную копию» → вставить текст в «Избранное» Telegram.
Восстановление: «Места» → «Восстановить из копии».

## Как править
Исходник — `src/app.html` (без `<html>/<head>`), из него `python3 build.py` собирает `index.html`.
Можно править и сам `index.html` напрямую — тогда `src/app.html` перестанет совпадать; лучше держать один источник.
